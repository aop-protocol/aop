# AOP Documentation

Welcome to the AOP (Agentic Observability Protocol) documentation!

## What is AOP?

AOP is a universal observability standard for AI agents - a "black box recorder" for agentic systems. It provides:

- **Universal event logging** across multiple AI agent protocols (MCP, A2A, AP2)
- **Distributed tracing** for multi-agent workflows
- **Production-ready performance** with <1ms overhead (P99)
- **Privacy-first design** with local storage
- **Zero runtime dependencies** for core functionality
