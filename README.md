# AOP (Agentic Observability Protocol)

> Universal observability standard for AI agents across MCP, A2A, and AP2 protocols

[Under active development - v0.1.0-alpha coming soon]

## What is AOP?

AOP is a universal observability protocol for AI agents - think of it as a "black box recorder" for agentic systems. It provides:

- 🔒 **Privacy-first**: Local storage, encryption, hashing
- 🌍 **Protocol-agnostic**: Works with MCP, A2A, and AP2
- 📊 **Production-ready**: <1ms overhead, audit trails built-in
- 🔓 **Open source**: MIT licensed, community-driven
