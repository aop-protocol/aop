## Supported Versions

Currently in alpha - no production use yet.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :x: Alpha only     |

## Reporting a Vulnerability

**DO NOT** open public issues for security vulnerabilities.

Email: asing349@ucr.edu [Subject: "AOP-Security"]

Alternatively: Use GitHub Security Advisories (private disclosure)

Response time: 48 hours

## Security Features

AOP includes:
- Event signing (ECDSA)
- Storage encryption (AES-256)
- Field hashing (SHA-256)
- Privacy modes
- Audit trails
